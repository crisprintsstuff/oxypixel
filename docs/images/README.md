# Screenshots

`editor.png`, `editor-frames.png`, and `pack.png` are screenshots of the OxyPixel 0.9.0 window, captured from a build of this repository on 2026-10-26. The drawing in them, `campfire.oxypix`, was made for the capture: a 64×64 scene with five layers, four named frames, and two animation tags. It is original project art, not a mockup and not artwork from another editor.

These files are part of this repository and are covered by the MIT license in the repository root.

# Shortcuts

Letter shortcuts are ignored while a text field is focused. Escape leaves the text field.

| Keys | Action |
| --- | --- |
| B | Pencil |
| E | Eraser |
| G | Fill |
| I | Eyedropper |
| L | Line |
| R | Rectangle |
| O | Ellipse |
| M | Rectangular selection |
| W | Magic wand: select the area the fill tool would reach |
| X | Swap colors |
| [ ] | Brush size |
| Ctrl+Z | Undo |
| Ctrl+Y, Ctrl+Shift+Z | Redo |
| Ctrl+N | New document |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+Shift+N | New frame |
| Ctrl+Shift+L | New layer |
| Ctrl+A | Select all |
| Ctrl+D | Deselect |
| Esc | Stop playback, cancel a shape preview, or deselect |
| Delete, Backspace | Clear pixels in the selection |
| Ctrl+C | Copy the selection to the system clipboard and the in-memory patch |
| Ctrl+V | Paste a system image on the active frame, or the in-memory patch when the clipboard has no image |
| Arrow keys | Nudge the selection by one pixel |
| P | Pixel-perfect pencil. One-pixel strokes drop the extra corner of a diagonal step |
| D | Shade with the pencil. Left steps a pixel to the next palette swatch, right to the one before |
| T | Wrap drawing that leaves an edge onto the opposite edge |
| Shift+T | Tiled view: the canvas repeated 3 by 3. Export is still one copy |
| S | Snap pencil, fill, and shapes to the nearest palette color. The eraser still clears |
| Shift+H | Flip the selection horizontally, or the active cel when nothing is selected |
| Shift+V | Flip the selection vertically, or the active cel when nothing is selected |
| Shift+. | Rotate that area 90 degrees clockwise |
| Shift+, | Rotate that area 90 degrees counter-clockwise |
| Ctrl+Shift+. | Rotate that area 180 degrees |
| Ctrl+Plus, Ctrl+Minus | Zoom by one whole-pixel step |
| Ctrl+0 | Fit the canvas |
| Enter | Play or pause |
| Comma, period | Previous or next frame |
| Space+drag, middle-drag | Pan |
| Wheel | Zoom toward the pointer, one whole-pixel step |
| Alt+click | Pick a color without changing tools. With select or the wand, cut the new area out of the selection |
| Shift+drag, Shift+click | With select or the wand, add the new area to the selection |
| Ctrl+drag | Move the reference image under the pointer. Without Ctrl, tools draw over it |
| Shift while drawing a line or shape | 45-degree lines, square rectangles and ellipses |
| Right-drag | Use the secondary color |
| Ctrl+Q | Quit |

The rectangle and ellipse tools outline by default. Turn on **Fill shape** for a filled stamp. The eraser is freehand only.

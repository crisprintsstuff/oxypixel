A Blazing Fast,
Pure Rust 2D Pixel Art Editor

OxyPixel is a lightweight, high-performance pixel art suite targeting digital illustrators. Built entirely in Rust with a custom engine and an immediate-mode interface, it delivers a focused, native experience without the overhead of heavy game engines.

Download
Core Technology

Built for Uncompromising Speed

OxyPixel strips away bloat. It leverages Rust's memory safety and performance alongside immediate-mode rendering to provide a completely fluid drawing experience.

oxypixel-core

Modular Data Engine

A highly decoupled, native Rust engine exclusively handling 2D pixel data manipulation. Clean separation of concerns allows for extreme stability, rapid memory operations, and headless testing capabilities.

egui

Immediate-Mode UI

A highly responsive, zero-lag graphical interface built on the egui framework. Because the UI is re-drawn every frame, tool switching, panning, and drawing are incredibly snappy with virtually zero input latency.

Standalone

True Independence

Completely independent architecture. Unlike other popular pixel art tools that rely on heavy game engines (like Godot) or bloated C++ web-wrappers, OxyPixel is a small, natively compiled binary.
